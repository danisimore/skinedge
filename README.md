# SkinEdge

Поиск арбитражных возможностей на рынках игровых предметов CS2, Dota 2 и Rust.
Система только анализирует рынок и присылает уведомления. Покупок и продаж она не делает.

## Состояние

| Этап | Что готово |
| --- | --- |
| 0. Каркас | pyproject, pytest, ruff, mypy, `.env.example` |
| 1. Финансовое ядро | Decimal-деньги, правила комиссий в YAML, расчёт маршрута, CLI `skinedge fees` |
| 2. Skinport | Реальные цены `/v1/items` и статистика продаж `/v1/sales/history`, история в SQLite |
| 3. DMarket | Лучшие цены и заявки (ask/bid), последние сделки, комиссия продавца из API |
| 4. Сканер | `skinedge scan`: маршруты Skinport ↔ DMarket в обе стороны, курс ЕЦБ, виртуальные сделки и отчёт `skinedge paper` |
| 5. Telegram | `skinedge telegram setup/test`, уведомления о новых возможностях из `skinedge scan` |
| 6. Фоновый запуск | `skinedge run`: скан по расписанию, тревога при сбоях, ежедневный отчёт в Telegram, очистка базы |
| 7. CSFloat | Самые дешёвые лоты CSFloat, маршруты CSFloat → Skinport и CSFloat → DMarket |
| 8. Dota 2 и Rust | Сканер и фоновый запуск проходят по CS2, Dota 2 и Rust (`--games`) |
| 9. Market.CSGO | Цены и реальные продажи Market.CSGO (а также market.dota2.net и rust.tm), маршруты в обе стороны |
| 10. Lis-Skins | Публичный прайс-лист Lis-Skins (CS2, Dota 2, Rust), покупка на Lis-Skins с продажей на Skinport, DMarket или Market.CSGO |
| 11. Интерфейс | Настройки сканера и журнал реальных сделок в браузере |
| 12. Приложение | Одна точка входа `SkinEdge.cmd` без окна консоли: сканер запускается кнопкой, найденные сделки появляются карточками с картинками |

Steam решено не добавлять: выручка там остаётся в Steam Wallet и не выводится.

Сделки на Skinport с 28.10.2026 по умолчанию не ищутся: пополнить и вывести деньги
там можно только через SWIFT, без криптовалюты. Цены и продажи Skinport по-прежнему
загружаются: по ним выбираются ликвидные предметы, считается тренд цены и выбираются
предметы для CSFloat. В приложении карточки сделок через Skinport не показываются
(и найденные раньше тоже), а в журнале Skinport не предлагается; прежние записи с
ним остаются как есть. Вернуть сделки на Skinport — флаг `--skinport` у `scan`, `run`
и `app` (`SkinEdge.cmd --skinport`).

## Установка

Нужен Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env    # Windows: copy .env.example .env
pytest
```

## Проверка расчёта вручную

```bash
skinedge fees --buy-market skinport --buy 100 --sell-market csfloat --sell 110 --usd-per-eur 1.10
skinedge fees --buy-market csfloat --buy 100 --sell-market skinport --sell 120 --usd-per-eur 1.10 --deposit sepa
skinedge fees --buy-market skinport --buy 100 --sell-market steam --sell 130 --target-roi 0.1
skinedge rules
```

Команда показывает полную стоимость покупки, чистую выручку, прибыль, ROI,
безубыточную цену продажи, запас прочности, каждую комиссию с её статусом и все оговорки.

Курсы задаются вручную: `--usd-per-eur` (курс ЕЦБ) для маршрутов с USD и
`--rub-per-eur` (курс ЦБ РФ) для маршрутов с рублями. Поверх курса применяется спред
`SKINEDGE_FX_SPREAD` (по умолчанию 1%): реальный курс площадки и банка неизвестен.

## Реальные цены Skinport

```bash
skinedge fetch skinport          # загрузить цены и статистику продаж CS2, сохранить в историю
skinedge item "AK-47 | Redline (Field-Tested)"   # последние цены и продажи предмета
skinedge item redline            # поиск по части названия
```

- API Skinport публичный, ключ не нужен. Лимит 8 запросов за 5 минут на endpoint,
  ответы кешируются площадкой на 5 минут; адаптер соблюдает лимит и кеширует так же.
- Есть и недокументированный лимит. 27.10.2026 при 24 запросах в час (три игры раз
  в 15 минут) Skinport ответил 429 «Your connection is being rate limited» и не
  пускал ровно час, хотя лимит 8 за 5 минут не превышался. С одной CS2 (8 запросов
  в час) блокировок не было. Поэтому статистика продаж перечитывается раз в час, а
  фоновый запуск сканирует Dota 2 и Rust через проход (см. «Фоновый запуск»).
- Запрос идёт с `tradable=1`: только лоты, которые можно сразу передать.
- Skinport отдаёт сводку по названию (минимальная цена и количество лотов), а не
  конкретные лоты: float, фазы и наклейки по ним неизвестны.
- При 429 и 5xx адаптер делает до 3 попыток с учётом `Retry-After`. Если Skinport
  просит ждать дольше минуты, повторов нет: запросы к Skinport встают на паузу до
  указанного срока, игры в эти проходы пропускаются сразу, без ожидания.
- История пишется в `data/skinedge.db` (`SKINEDGE_DB_PATH`), каждая загрузка добавляет строки.
- Под одним названием Skinport смешивает предметы с наклейками и редкими паттернами,
  поэтому максимум и среднее продаж содержат выбросы. Для оценки цены продажи
  используем медиану.
- Котировка старше `--max-age` минут (по умолчанию 15) помечается как устаревшая.

## DMarket

Нужны ключи Trading API (dmarket.com → настройки аккаунта → API) в `.env`:
`SKINEDGE_DMARKET_PUBLIC_KEY` и `SKINEDGE_DMARKET_SECRET_KEY`. Ключи дают право
торговать, но SkinEdge вызывает только методы чтения.

```bash
skinedge fetch dmarket --limit 200          # ask/bid по 200 самым ликвидным предметам Skinport
skinedge sales dmarket "AK-47 | Redline (Field-Tested)"   # последние 20 сделок
```

- Каждый запрос подписывается Ed25519: `METHOD + путь?query + тело + X-Sign-Date`.
- Комиссия продавца берётся из `/exchange/v1/customized-fees` (статус `official`).
  Сниженные ставки по отдельным предметам пока не применяются: единицы их
  ценового диапазона не подтверждены, общая ставка консервативнее.
- Опубликованных лимитов нет, адаптер делает не больше 1 запроса в секунду.
- Комиссии вывода DMarket взяты с экрана вывода в аккаунте (26.10.2026), по умолчанию
  Visa: 0.75% + 0.35 USD. Другой способ: `SKINEDGE_DMARKET_WITHDRAW=sepa` в `.env`
  (visa, sepa, payoneer, usdc, bitcoin, skrill и др., список: `skinedge rules`).
  Фиксированная часть считается с каждой продажи, как будто каждая выводится отдельно.
  Комиссия пополнения DMarket неизвестна.

## CSFloat

Нужен ключ CSFloat API (csfloat.com → профиль → Developers) в `.env`:
`SKINEDGE_CSFLOAT_KEY` (подходит и `SKINEDGE_CSFLOAT_API_KEY`). Без ключа
сканер работает без CSFloat.

- Используется один метод: `GET /api/v1/listings` с сортировкой по цене, только
  лоты «купить сейчас» (аукционы не берутся).
- Истории продаж в API нет, поэтому CSFloat только площадка покупки: продажа
  оценивается по реальным сделкам DMarket или Market.CSGO (Skinport — с `--skinport`).
- Лимит API 200 запросов в час на ключ (заголовки `x-ratelimit-*`). Один предмет —
  один запрос, поэтому за проход проверяется `--csfloat` предметов (по умолчанию 40,
  `0` выключает). При проходе раз в 15 минут это 160 запросов в час. 20 запросов
  остаются в запасе: когда лимит доходит до запаса, CSFloat пропускается до сброса.
- Проверяются только предметы с продажами на Skinport (от 5 за 7 дней), по кругу:
  каждый проход продолжает с того места, где остановился прошлый.
- Цена лота CSFloat зависит от float и наклеек конкретного предмета, а продажа
  оценивается по медиане всех продаж под этим названием. Перед покупкой смотри сам лот.
- Считается, что USD уже лежат на балансе CSFloat (комиссия пополнения не учитывается).

## Market.CSGO

Ключ не нужен: используются только публичные файлы API v2
(<https://market.dota2.net/docs-v2>). У каждой игры свой сайт с тем же API:
market.csgo.com (CS2), market.dota2.net (Dota 2), rust.tm (Rust).

- `prices/RUB.json` — минимальная цена лота по каждому названию, одним файлом на игру.
  Поле `volume` в документации не описано; сравнение с историей продаж показало, что
  это не число продаж, поэтому оно считается числом лотов.
- Продажа на Market.CSGO подтверждается реальными сделками, как на DMarket: для
  кандидатов загружается файл истории (`full-history/{id}.json`, до 6000 последних
  продаж, цены в рублях, долларах и евро). Сделки считаются по эпизодам, нужно не
  меньше 5 за 7 дней. Файлы обновляются примерно раз в час, поэтому предмет,
  проверенный меньше часа назад, повторно не загружается.
- Не больше 2 запросов в секунду (документация грозит удалить ключ за 5+ в секунду).
- Цены, продажи и комиссии в рублях: валюта аккаунта Market.CSGO выбирается при
  регистрации, у этого аккаунта это RUB. Прибыль считается в EUR по официальному
  курсу ЦБ РФ (ЕЦБ курс рубля не публикует) со спредом `SKINEDGE_FX_SPREAD`. Реальные
  потери при обмене рублей могут быть больше 1%.
- Записи, сделанные, когда Market.CSGO считался в EUR (до 28.10.2026), остаются в EUR:
  котировки и продажи в EUR сканер больше не использует, виртуальные сделки
  проверяются только по данным в своей валюте, а сделку журнала интерфейс просит
  поправить: вписать цену в рублях.
- Комиссии (5% с продажи, 0% на покупку, вывод до 5%, деньги от продажи через 8 дней)
  взяты из сторонних обзоров и требуют проверки в аккаунте. Для Dota 2 и Rust
  считаются такими же.
- Ссылка в карточке и уведомлении ведёт на страницу предмета CS2
  `https://market.csgo.com/ru/{название}` (проверено 28.10.2026). У Dota 2 и Rust
  в адресе страницы есть внутренний номер предмета (`/item/{classid}-{instanceid}-{название}/`),
  которого нет в прайс-листе, поэтому ссылок на их предметы пока нет.
- `--no-marketcsgo` отключает площадку.

## Lis-Skins

Ключ не нужен: используются публичные выгрузки цен из документации
(<https://lis-skins.stoplight.io/docs/lis-skins/>), один файл на игру:
`https://lis-skins.com/market_export_json/{csgo,dota2,rust}.json`.

- Lis-Skins — только площадка покупки, как CSFloat: истории продаж в API нет.
  Маршруты: Lis-Skins → DMarket или Market.CSGO (→ Skinport только с `--skinport`).
- Цена покупки — `unlocked_price`, самый дешёвый лот, который можно вывести в Steam
  сейчас. Лоты с блокировкой (`unlock_at`) бывают дешевле, но их нельзя забрать до
  даты разблокировки.
- Валюта в файле не указана. Цены в долларах: страница предмета показывает ту же
  цену со знаком $ (проверено 27.10.2026). Что `price` — минимум всех лотов,
  `count` — число лотов, а `unlocked_price` — минимум разблокированных, проверено
  по полным спискам Dota 2 и Rust.
- В уведомлении ссылка ведёт на страницу предмета Lis-Skins из выгрузки.
- Комиссии (0% на покупку, пополнение без комиссии) взяты из обзора steamdb
  (июль 2026) и требуют проверки в аккаунте. Для Dota 2 и Rust считаются такими же.
- `--no-lisskins` отключает площадку.

## White.market

Ключ не нужен: используется публичная выгрузка цен из документации для партнёров
(<https://api.white.market/docs_partner/5-skins-buy/prices.html>):
`https://export.white.market/v1/prices/730.json` и описание выгрузки
`730.json.meta.json`. Пополнение и вывод на White.market — криптовалютой.

- Только CS2: выгрузок для Dota 2 и Rust нет (ответ 404, проверено 28.10.2026).
- Только площадка покупки, как Lis-Skins: истории продаж в выгрузке нет.
  Маршруты: White.market → DMarket или Market.CSGO (→ Skinport только с `--skinport`).
- Цены в USD (по документации), строкой с тремя знаками. Время цен — `data_as_of` из
  описания выгрузки, поэтому устаревшую выгрузку сканер отбросит по `--max-age`.
- Одно название бывает в нескольких строках (фазы Doppler и другие варианты): берётся
  самая дешёвая строка, лоты складываются. Ссылка в уведомлении — ссылка на самый
  дешёвый лот из выгрузки.
- Файл около 10 МБ, загружается раз за проход CS2.
- Комиссии с официального обзора площадки (news.white.market, обновлён 22.07.2026):
  0% на покупку, пополнение без комиссии площадки. Сетевая комиссия блокчейна при
  пополнении не учитывается.
- `--no-whitemarket` отключает площадку.

## CS.Deals

Нужен ключ CS.Deals API (cs.deals → Settings → API) в `.env`: `SKINEDGE_CSDEALS_KEY`.
Без ключа сканер работает без CS.Deals. Пополнение и вывод — криптовалютой.

- Ключ даёт полный доступ к аккаунту, включая покупку и вывод криптовалюты.
  SkinEdge вызывает с ним только два метода чтения (`GET /prices/all` и
  `GET /listings`), другие адаптер не пропускает. Включи в CS.Deals 2FA на вывод и
  не держи там лишний баланс.
- Только площадка покупки: лоты есть у малой части предметов (в CS2 у 3 254 из 48 тысяч),
  а продаются в основном кейсы. Маршруты: CS.Deals → DMarket или Market.CSGO
  (→ Skinport только с `--skinport`). Все три игры.
- Цена — `lowest_listing_price` из сводки `/prices/all` (центы USD). Сводка
  пересобирается раз в минуту и совпала с живыми лотами у всех предметов
  (проверено 28.10.2026), время цены — `generated_at`.
- Сводка учитывает и лоты под трейд-локом, которые нельзя вывести в Steam до
  `trade_locked_until`. Поэтому за проход читаются лоты за последние 9 дней
  (`/listings`, новые первыми; лок кончается не позже чем через 8 дней после
  выставления лота): в CS2 это 1 страница, в Dota 2 — 7, в Rust — 12–13, по
  запросу в секунду. Если заблокированный лот не дороже цены из сводки, цена
  доступного лота неизвестна, и предмет пропускается.
- Ссылки на страницу предмета у CS.Deals нет (сайт-приложение без адресов
  предметов), ссылка в уведомлении ведёт на рынок `https://cs.deals/market`.
- Комиссии: 0% на покупку (официальная страница cs.deals/fees, 28.10.2026; steamdb
  в июле писал 2%), пополнение криптовалютой без комиссии (steamdb, 01.07.2026,
  нужно проверить в аккаунте). Сетевая комиссия блокчейна не учитывается.
- `--no-csdeals` отключает площадку.

## Сканер

```bash
skinedge scan                       # загрузить свежие цены и найти возможности
skinedge scan --games dota2,rust    # только Dota 2 и Rust (по умолчанию cs2,dota2,rust)
skinedge scan --min-roi 0.08 --min-profit 1 --top 30
skinedge scan --no-fetch            # искать по уже загруженным ценам (не старше --max-age)
skinedge paper                      # что стало с прошлыми сигналами
```

- `scan` загружает Skinport (цены и продажи, только как источник данных), затем DMarket, Market.CSGO, Lis-Skins, White.market и CS.Deals по самым
  ликвидным предметам Skinport (`--limit`, `--min-price`, `--max-price`), берёт
  комиссию DMarket из API, курс USD от ЕЦБ и курс RUB от ЦБ РФ (`--usd-per-eur` и
  `--rub-per-eur` задают курсы вручную, оба сразу).
- Игры сканируются по очереди и независимо (`--games`, по умолчанию `cs2,dota2,rust`),
  `--limit` и диапазон цен действуют в каждой игре. Если одна игра не загрузилась,
  остальные сканируются дальше. CSFloat и White.market — только CS2. Комиссия продавца DMarket
  берётся из API для каждой игры, комиссии Skinport и блокировка 7 дней считаются
  одинаковыми для всех игр (это ещё нужно сверить для Dota 2 и Rust).
- Предметы сопоставляются по `market_hash_name`. Маршруты: DMarket → Market.CSGO и
  Market.CSGO → DMarket, а также покупка на CSFloat, Lis-Skins, White.market или CS.Deals
  с продажей на DMarket или Market.CSGO (см. разделы этих площадок).
  С `--skinport` к ним добавляются покупка и продажа на Skinport: Skinport ↔ DMarket,
  Skinport ↔ Market.CSGO, CSFloat, Lis-Skins, White.market и CS.Deals → Skinport. Деньги
  считаются уже лежащими на балансе.
- Покупка: минимальная цена предложения. Продажа: минимальная цена на площадке
  продажи минус цент, но не выше медианы реальных продаж за 7 дней. Продаж за 7 дней
  должно быть не меньше 5, иначе предмет пропускается: цена лота без сделок ничего
  не говорит о спросе.
- Статистику продаж Skinport отдаёт сводкой. У DMarket её нет, поэтому сканер сначала
  отбирает кандидатов по минимальному лоту (верхняя граница цены), а затем загружает
  последние 20 сделок по каждому (`--verify`, по умолчанию 40 предметов на каждую
  площадку покупки, ~1 запрос в секунду). Так же проверяется продажа на Market.CSGO
  (см. раздел Market.CSGO). Сделки считаются по эпизодам: покупки с разницей меньше 5 минут — одна
  массовая покупка. Нужно не меньше 5 эпизодов за 7 дней, цена — медиана эпизодов,
  но не выше самого свежего эпизода.
- Отсекаются котировки старше `--max-age` минут (30), прибыль меньше `--min-profit`
  (0.50 EUR) и ROI меньше `--min-roi` (5%).
- Сначала показываются полные расчёты, затем по ROI. Флаги: неполный расчёт,
  подозрительно высокий ROI, падающая цена (медиана Skinport за 24ч ниже 30-дневной
  больше чем на 5%), фазы Doppler, цена из сводки без float и наклеек.
- Маршруты с продажей на DMarket учитывают комиссию вывода выбранным способом.
  В маршрутах с покупкой на DMarket считается, что USD уже лежат на балансе
  (комиссия пополнения не учитывается).

### Виртуальные сделки

Каждая возможность, прошедшая стандартные пороги (прибыль от 0.50 EUR и ROI от 5%),
записывается как виртуальная сделка. Прогоны с пониженными порогами в журнал не пишут.
Повтор того же маршрута записывается не чаще раза в сутки, `--no-paper` отключает запись.
`skinedge paper` пересчитывает каждую сделку по ценам и реальным продажам площадки
продажи через 24 часа, 3 дня и 7 дней с теми же комиссиями и курсом. Сделки, записанные
прежней моделью оценки, остаются в базе, но в отчёт не входят. Главная точка: 7 дней, когда купленный предмет можно
передать и выставить. Для контрольных точек нужны свежие цены, поэтому нужен
фоновый запуск `skinedge run` или `scan` хотя бы раз в день.

## Telegram

1. Создай бота у @BotFather и запиши токен в `.env`: `TG_BOT_TOKEN=...`
   (или `SKINEDGE_TELEGRAM_BOT_TOKEN`).
2. Напиши своему боту `/start`.
3. `skinedge telegram setup --save` найдёт этот чат и допишет в `.env` строку
   `SKINEDGE_TELEGRAM_CHAT_ID=...` (подходит и имя `TG_CHAT_ID`).
4. `skinedge telegram test` отправит тестовое сообщение.

После этого `skinedge scan` присылает сводку новых возможностей: только прошедшие
стандартные пороги, не больше 5 за раз, повтор того же маршрута не чаще раза в сутки.
`--no-notify` отключает отправку. Токен не печатается и не попадает в логи и ошибки.

## Фоновый запуск

Обычно сканер запускают кнопкой в приложении (см. «Приложение» ниже). Команда
`skinedge run` делает то же без интерфейса, в окне консоли:

```bash
skinedge run                    # проход каждые 15 минут, пока не остановят (Ctrl+C)
skinedge run --every 10         # чаще, но не меньше 5 минут (Skinport обновляет данные раз в 5 минут)
skinedge run --iterations 2     # два прохода и выход, для проверки
```

Без интерфейса на Windows то же самое запускает `scripts\run-skinedge.cmd`
(двойной щелчок или из консоли, параметры те же). Скрипт сам переходит в папку проекта, где лежат `.env`
и база, и берёт `skinedge` из `.venv`, если он там есть.

Каждый проход делает то же, что `skinedge scan` по всем играм: свежие цены Skinport и DMarket,
проверка реальных продаж DMarket, поиск, журнал виртуальных сделок и сводка новых
возможностей в Telegram. Параметры `--limit`, `--min-price`, `--max-price`, `--verify`,
`--min-profit`, `--min-roi`, `--games`, `--no-paper`, `--no-notify` те же. Сделок система
не совершает.

- При трёх играх первая в списке (CS2) сканируется каждый проход, а Dota 2 и Rust по
  очереди: так к Skinport уходит около 11 запросов в час вместо 24.
- Сбой прохода (площадка не ответила, пропала сеть) не останавливает работу: ошибка
  пишется в лог, следующий проход идёт по расписанию. После 3 сбоев подряд в Telegram
  приходит тревога, после восстановления сообщение, что всё снова работает.
- Курсы ЕЦБ и ЦБ РФ обновляются раз в 6 часов. Если один из них недоступен,
  используются прежние курсы не старше 72 часов (в выходные курсы не публикуются).
- Раз в день, начиная с 10:00 по местному времени (`--report-hour`, `--no-report`),
  в Telegram приходит отчёт по виртуальным сделкам за 30 дней и число проходов.
- Раз в день база чистится. Сохраняются только сравниваемые предметы и предметы
  открытых виртуальных сделок. Через 2 дня цены прореживаются до одной записи на
  предмет за 6 часов, через 40 дней удаляются. Виртуальные сделки и отметки об
  уведомлениях не удаляются.
- Лог: `logs/skinedge.log` (5 файлов по 1 МБ), путь меняет `SKINEDGE_LOG_PATH`.
  Токен бота и ключи в лог не попадают.
- Второй запуск с той же базой не стартует, пока работает первый: работающий процесс
  раз в минуту оставляет отметку в базе. Если окно закрыли аварийно, новый запуск
  возможен через 20 минут или сразу с `--force`.

### Автозапуск при входе в Windows (по желанию)

Нажми Win+R, введи `shell:startup` и положи в открывшуюся папку ярлык на
`SkinEdge.cmd`. В свойствах ярлыка допиши в поле «Объект» после кавычек ` --scan`,
чтобы сканер запускался сразу, и выбери «Окно: свёрнутое в значок», чтобы не мелькала
консоль. Чтобы отключить автозапуск, удали ярлык.

## Приложение

Двойной щелчок по `SkinEdge.cmd` в папке проекта. Окно консоли не остаётся:
приложение работает в фоне (через `pythonw`) и открывает в браузере страницу
`http://127.0.0.1:8765/`. Она работает только на этом компьютере, с той же базой.
Ход работы пишется в `logs/skinedge.log`. Повторный запуск `SkinEdge.cmd` просто
открывает уже работающее приложение. Без `.venv` то же самое: `pythonw -m skinedge app`
(`--port 8766` — другой порт, `--scan` — сразу запустить сканер, `--skinport` — искать
и сделки на Skinport).

Закрытие вкладки браузера приложение не выключает: сканер продолжает работать.
Выключить — кнопкой «Выключить» вверху страницы (сканер тоже остановится). Перед
обновлением SkinEdge выключи приложение, иначе останется работать старая версия.

- **Сканер.** Кнопка «Запустить сканер» начинает проходы каждые 15 минут, как
  `skinedge run`, с настройками из вкладки «Настройки сканера». «Остановить»
  прерывает ожидание сразу, а начатый проход доводит до конца. Найденные сделки
  появляются карточками: картинка предмета, игра, где купить и где продать (название
  площадки — ссылка на предмет), цена покупки, ожидаемая цена продажи, чистая прибыль
  в EUR и ROI, на сколько дней заморожен капитал и оговорки. Новые сделки помечены
  «Новая». Карточки старше двух часов скрываются: цены уже могли уйти. Кнопка
  «Купил — внести в журнал» заполняет форму покупки данными карточки. Если сканер
  уже работает в другом окне (`skinedge run`), приложение показывает его находки,
  а кнопка запуска появится, когда то окно закроют.
- **Картинки** берутся из списка предложений DMarket (`GET /marketplace-api/v2/offers`
  с `withImages=true`, только чтение) и хранятся в базе: один запрос на предмет, не
  больше 8 за проход. Если на DMarket нет лотов предмета, вместо картинки значок.
- **Журнал сделок.** Купил предмет — внеси его: игра, название, дата, где куплен и
  за сколько, где собираешься продать и сколько он там стоит сейчас. Валюта берётся
  из площадки, курсы USD и RUB записываются на день записи. Подсказка под ценой показывает
  последний лот, который видел сканер. Когда продашь, нажми «Записать продажу»:
  дата, площадка и цена лота. Прибыль считается в EUR теми же правилами комиссий,
  что у сканера (комиссия покупателя, продавца и вывод денег), с разбивкой по
  строкам. В таблице видно, до какого дня действует Trade Protection и когда
  деньги от продажи можно вывести. Сверху — прибыль по проданным, вложено в
  открытые и ожидаемая прибыль по текущим ценам.
- **Настройки сканера.** Диапазон цен (по Skinport, EUR), сколько самых ликвидных
  предметов брать в каждой игре, продаваемость (продаж за 7 дней на площадке
  продажи) и пороги сигнала (прибыль и ROI). Настройки хранятся в базе, и сканер
  применяет их со следующего прохода, без перезапуска; `skinedge scan` тоже. Пока
  они не сохранены, действуют стандартные. Виртуальные сделки всегда записываются
  по стандартным порогам, чтобы их итоги можно было сравнивать.
- Сервер принимает запросы только с адреса 127.0.0.1 и только от своей страницы.

## Как устроен расчёт

- Деньги хранятся в `Decimal`, float запрещён. Комиссии округляются до центов.
- Итог переводится в EUR консервативно: расходы округляются вверх, доходы вниз.
- Комиссии лежат в `src/skinedge/fees/rules.yaml`: отдельное правило на площадку,
  операцию (`buy`, `sell`, `deposit`, `withdraw`) и способ оплаты или вывода.
  У каждого правила есть источник, дата проверки и статус:
  `official`, `account`, `third_party` или `unknown`.
- Если комиссия неизвестна или для операции нет правила, расчёт помечается как неполный.
- Steam считает комиссию от суммы продавцу: `floor(max(x·5%, 0.01)) + floor(max(x·10%, 0.01))`.
  Выручка в Steam Wallet помечается отдельно, это не выводимые деньги.
- Безубыточность, максимальная цена покупки и нужная цена продажи для ROI ищутся
  бинарным поиском по центам, поэтому учитывают минимальные комиссии, округление и пороги.
- Капитал считается замороженным минимум на 14 дней: 7 дней Trade Protection
  у купленного предмета и 7 дней до выплаты после продажи (8 дней на Market.CSGO).

## Комиссии требуют проверки

Комиссии Skinport, CSFloat (в том числе 0% на покупку), Market.CSGO, Lis-Skins и Steam взяты из сторонних
обзоров (июль 2026) и имеют статус `third_party`. Комиссия продавца DMarket приходит
из API, комиссии вывода DMarket проверены в аккаунте (`account`). После проверки в своих аккаунтах поменяй `verification` на `account` и обнови `verified_at`.
Свой файл правил можно подключить через `SKINEDGE_FEE_RULES_PATH`.
